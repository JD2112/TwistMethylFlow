# Security Policy

## Supported Versions

We actively monitor and patch security vulnerabilities in `milou`. The table below outlines the support status for different releases:

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x  | :white_check_mark: |
| < 1.2  | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub issues.**

If you discover a security vulnerability in this project, we appreciate your help in disclosing it to us responsibly. You can report vulnerabilities via:

1. **GitHub Private Vulnerability Reporting:** Navigate to the "Security" tab of this repository on GitHub, click on "Advisories", and then "Report a vulnerability". This is the preferred method as it creates a private channel for collaboration.
2. **Direct Contact:** If you prefer, you can reach out directly via email to **Jyotirmoy Das** (the maintainer).

### What to Include in Your Report

To help us triage and resolve the issue quickly, please include:
- A detailed description of the vulnerability.
- Steps, scripts, or instructions to reproduce the issue.
- The potential impact (e.g., privilege escalation, information leakage).

### Our Response Process

- **Acknowledgement:** We will acknowledge receipt of your report within 48 hours.
- **Triage:** We will investigate the issue and determine the appropriate fix.
- **Patching:** If a vulnerability is confirmed, we will coordinate a patch and release a new version as soon as possible.
- **Credit:** We will gladly credit you for the discovery in our release notes (unless you prefer to remain anonymous).
